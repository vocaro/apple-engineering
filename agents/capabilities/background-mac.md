# Background mac

Host views in an offscreen window that never becomes key and act through in-process accessibility; drive another owned process by PID through accessibility, never by activation, global input, name or bundle ID. Keep view semantics in headless tests. A locked screen or sleeping display leaves these tests unmeasured. Pin render settings and review every recorded baseline. Local StoreKit tests and Xcode runs switch the StoreKit environment that every copy of a bundle ID on the Mac shares; coordinate them with sandbox and archive checks. Menus, focus, Mac UI tests and VoiceOver are foreground work: hosted runner by default, attended only with explicit owner authorization.
