# Measurement

Run whole-machine measurements as exclusive admitted work, in fresh child processes, from release builds. Keep peak RSS, lifetime and sampled footprint distinct. A ceiling or time limit spoiled by memory pressure or core wait is unmeasured (exit 3), never green. Count work instead of time where possible, bound reruns, record exact execution identity and host activity, and qualify the actual hardware. On macOS, Vision's compile follows the executable's basename and code-signing identifier; run only release builds under a product's name and give probes their own. For model output, follow guides/model-evaluation.md: per-item rows, paired discordant counts, item-clustered tests and a call ceiling declared before the first call.
